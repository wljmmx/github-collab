# Coder Agent Memory

Daily coding logs and technical insights for the coder agent.

## Format

Each file is named by date: `YYYY-MM-DD.md`

## Contents

- Coding tasks completed
- Solutions to technical problems
- Bugs found and their fixes
- Code patterns and techniques discovered
- Lessons learned during development
- Tech stack decisions and rationale

## Usage

Read the file for the current date to learn about recent coding work.
Update it with new insights after each coding session.
