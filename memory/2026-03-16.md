## Model-Switch-Notify Skill v3.0

### 任务
用户要求完善模型切换通知 skill，实现：
1. 记录每个 agent 上次对话使用的模型
2. 每次对话前检查模型是否变化
3. 变化时推送通知用户
4. 心跳检测机制
5. 消息中断时下次会话第一时间通知
6. 只使用 SQLite 存储

### 已完成功能

#### 1. 心跳检测机制
- 每次会话回复时调用 `check` 命令
- 自动检查 pending_notify（待发送通知）
- 自动检查模型是否变化
- 更新心跳时间戳

#### 2. 中断通知处理
- 消息发送失败时调用 `interrupt` 命令
- 保存 pending_notify 和 pending_message
- 下次会话 check 时自动返回待发送通知
- 发送后自动清除

#### 3. SQLite 存储
- 路径：`~/.openclaw/data/model-switch.db`
- 支持字段：
  - agent_id, last_model, last_notify
  - last_heartbeat（心跳时间戳）
  - pending_notify, pending_message（中断通知）
  - channel, session, updated_at

#### 4. 命令行工具
```bash
# 心跳检测
python3 check_model.py check --agent "coder" --current-model "xxx" --channel "qqbot" --session "xxx"

# 更新心跳
python3 check_model.py heartbeat --agent "coder" --current-model "xxx"

# 设置中断通知
python3 check_model.py interrupt --agent "coder" --model "xxx" --message "xxx"

# 获取状态
python3 check_model.py get --agent "coder"

# 列出所有
python3 check_model.py list

# 重置
python3 check_model.py reset --agent "coder"
```

#### 5. 返回值示例
```json
{
  "changed": true,
  "previousModel": "ollama/glm-5:cloud",
  "currentModel": "ollama/qwen3.5-code",
  "shouldNotify": true,
  "notifyMessage": "老板，模型已切换，当前使用：ollama/qwen3.5-code",
  "firstTime": false,
  "pendingNotify": false,
  "pendingMessage": null
}
```
