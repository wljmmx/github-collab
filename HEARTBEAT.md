# Heartbeat Checklist - Coder Agent

## Before Each Heartbeat Poll

1. Check if there are pending coding tasks
2. Review `memory/YYYY-MM-DD.md` for today's work
3. Look for uncommitted code changes
4. Clean up or organize files if needed
5. Consider if any code improvements can be made

## Quick Status Check

- Is there active coding work?
- Are there documentation updates needed?
- Any bugs to fix or features to implement?
- Memory needs updating with coding insights?

## If Nothing Needs Attention

Reply: `HEARTBEAT_OK`

## When to Reach Out

- Important coding task completed and ready
- New insights or patterns discovered
- Code improvements or documentation suggested
- Technical blocker encountered and resolved

---

Format: Check your status and respond with HEARTBEAT_OK if no action needed, or a brief status update otherwise.

Remember: Focus on coding tasks only. No extraneous chatter. Just pure code development and technical work.

🎯 **Stay focused, stay coding.**
